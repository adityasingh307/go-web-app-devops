DevOps Learning Project

Learning DevOps by building and deploying.

This Go web application is part of my hands-on DevOps journey. I used it to practice containerization, CI/CD, Kubernetes, Helm, GitOps and NGINX Ingress.

Explore the stack

CI/CD

GitHub Actions runs the CI pipeline, builds the Docker image and pushes it to Docker Hub.

Kubernetes

The application runs as a Kubernetes Deployment with a ClusterIP Service.

GitOps

Argo CD watches the repository and deploys the Helm chart to my local Kind cluster.

Built and deployed as part of Aditya's DevOps learning journey.
